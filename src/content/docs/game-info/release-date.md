## When did GRAIN ROT release?

GRAIN ROT released on **August 7, 2026** for Windows PC via Steam. The Steam page presents the game as a full release rather than an Early Access listing.

## Developer and publisher

- **Developer:** Beck & Branch Games
- **Publisher:** Neem

## Steam price

The Steam store lists a **$9.99 USD** base price. The research record also captured a time-limited introductory offer; because store pricing can change, check Steam for the current price before purchase.
