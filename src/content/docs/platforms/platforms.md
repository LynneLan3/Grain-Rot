## Is GRAIN ROT on PC?

Yes. The confirmed launch platform is **Windows PC via Steam**.

## Minimum PC requirements listed on Steam

The Steam listing records these minimum requirements:

| Requirement | Minimum listed value |
| --- | --- |
| Operating system | Windows 10 64-bit |
| Memory | 8 GB RAM |
| DirectX | Version 11 |
| Storage | 10 GB available space |
| Network | Broadband internet connection |

These values come from the Steam listing checked on 2026-08-11. Confirm the current store page before relying on them, since requirements can be updated.

## Console availability

The available evidence confirms Windows PC via Steam. It does not confirm PlayStation, Xbox, or Nintendo Switch release platforms, so this site does not state that a console version exists.
